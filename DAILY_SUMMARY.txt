THINGS LEARNED
--------------

- async / await with EF Core, and when you don't need it.

- AsNoTracking() and where NOT to use it (anything that saves).

- Paging with Skip() / Take(), and checking page number from the URL.

- TempData is only for redirects; AJAX should send the message in the
  response body.

- ViewModels with DataAnnotations for validation, and checking ModelState.

- Returning partial views and loading them with AJAX.
- The @section Scripts block in Razor, and why it doesn't work inside a
  partial.

- Bootstrap modals for delete confirmation.

- Tag Helpers: asp-for, asp-action, asp-route-*, query string filters.

- Git basics: checking the diff before committing.
